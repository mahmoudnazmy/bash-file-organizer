# 🐧 File Organizer Bash Script

A simple Bash automation script that organizes files automatically based on their type.

This project is part of my journey to become a SOC Analyst and practice Linux + Bash scripting skills 🚀

---

# ✨ Features

✅ Automatically creates folders if they don't exist  
✅ Organizes files by extension  
✅ Supports multiple file types  
✅ Simple and beginner-friendly Bash script  
✅ Helps keep directories clean and organized

---

# 📂 Supported File Types

| Category | Extensions |
|---|---|
| Images | jpg, jpeg, png, gif |
| Videos | mp4, mkv, avi |
| Documents | pdf, txt, docx |
| Scripts | sh, py, js |
| Archives | zip, rar, 7z |
| Others | any unsupported files |

# 🚀 How To Run

Clone the repository:

```bash
git clone https://github.com/mahmoudnazmy/file-organizer.git
```

Go to the project folder:

```bash
cd file-organizer
```

Make the script executable:

```bash
chmod +x files_organizer.sh
```

Run the script:

```bash
./files_organizer.sh
```
